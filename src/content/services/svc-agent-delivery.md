The method is itself public and self-improving: Specstride drives coding agents phase
by phase behind an LLM critic gate, diagnoses stuck phases, and learns per-phase
settings from its own run telemetry — reverting any change that regresses. The same
discipline wraps your workflow: nothing advances without evidence, and every artifact
carries its provenance.
