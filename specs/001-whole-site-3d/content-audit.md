# Content-Source Audit — 001-whole-site-3d (T093, FR-015 / SC-008)

**Scope**: every user-visible text string and asset in the 3D experience
(`src/islands/room3d/`, the pre-JS boot overlay in `src/layouts/Base.astro`,
and the island wrapper `src/components/RoomIsland.astro`).

**Rule (FR-015 / constitution P5)**: every string and asset must trace to a
mairp-owned source — the Astro content collections (`src/content/`),
`src/lib/site.ts` CV/bio data, the generated `src/content/repos.yaml`
(portfolio-sync), or mairp brand assets. Zero strings/assets may trace to the
reference demo (`/root/little-big-questions/room-viewer`).

**Audit method**: enumerated every literal string in the island (grep for JSX
text, labels, aria-labels, button text, status lines, CSS assets), then traced
each to its source. Assets: the island ships **no binary assets at all** — the
environment is procedural in-code geometry (`rooms/environment.tsx`), audio
cues are synthesized at play time (`audio/cues.ts`), fonts come from the
site's existing `@fontsource` packages via CSS vars.

## Result: PASS — 0 demo-traceable entries
